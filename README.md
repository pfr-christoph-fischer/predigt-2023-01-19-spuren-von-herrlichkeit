# Spuren von Herrlichkeit

Ach, wie sehr eine gewaltige Gottesbegegnung doch helfen könnte in Enttäuschung und Niedergeschlagenheit! Gott bleibt unverfügbar. Gotteserlebnisse gibt es nicht auf Abruf. Stattdessen gibt es seine beständige Zuwendung, die ganz anders aussieht als erwartet, und dennoch ausreicht für den alltäglichen Lebensweg.
